# QuadraFroyn V40 — Cloud Migration Service Page

This update replaces the previous generic Cloud Migration page with a dedicated, responsive cloud-migration experience while preserving the existing site routes, layout, navigation, footer, and other service pages.

## Included
- White editorial design with restrained blue, violet, cyan and coral accents.
- Bespoke CSS/SVG cloud architecture illustration in the hero.
- Interactive four-stage migration journey.
- Three detailed illustrative architecture concepts (not claimed client deployments).
- AWS, Microsoft Azure and Google Cloud ecosystem presentation.
- Security, disruption management, scalability and optimization principles.
- Working links to the existing `/contact` route.
- Responsive layouts, scroll reveal, reduced-motion support and custom interface visuals.

## Run locally
1. Extract the project.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Visit `/services/cloud-migration`.

For a production compilation check, run `npm run build` after dependencies are installed.

The page uses custom interface illustrations rather than portraying stock photos or other companies' products as QuadraFroyn client work. The concept case studies are explicitly labelled. No client names, production migrations, or measured outcomes are invented.
