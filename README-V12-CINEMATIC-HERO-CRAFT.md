# QuadraFroyn V12 — Cinematic Hero & Q Craft Rail

## Refinements
- Hero carousel now rotates through three distinct themes: a golden-hour cityscape, robotics/AI, and high-rise architecture.
- Hero art has a larger crop, a soft white blend, a lime angled accent, and reduced top-fold spacing.
- Craft service cards form a horizontally scrollable rail layered in front of the slightly reduced Q ring, with deeper shadows, glass-like surfaces, lime edge lighting, and hover lift.
- Updated the capability-card image set to better match data context, robotics, hardware, architecture, and collaborative technology.
- Improved diary-card depth and horizontal scroll snap presentation.
- Responsive overrides preserve horizontal swipe on mobile and keyboard-operable links/buttons.

## Run locally
```bash
npm install
npm run dev
```

Images are remote Unsplash URLs and therefore require an internet connection to load. A production build could not be run in the editing environment because project dependencies were not installed (`vite: not found`).
