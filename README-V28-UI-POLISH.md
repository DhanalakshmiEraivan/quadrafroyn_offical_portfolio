# V28 UI polish and competition experience

This update builds on the supplied QuadraFroyn project.

## Changes
- Corrected the footer newsletter form layout with aligned email and Subscribe controls, responsive stacking, improved contrast, and green hover/focus states.
- Polished mega-menu spacing and sizing; the Explore all products call-to-action now sizes to its content and remains responsive.
- Added a six-card competition capabilities section with staggered entrance animation, hover lift, green accents, and reduced-motion support.
- Removed Digital Marketing items/content from the services navigation, footer service links, and service/internship-related content data.
- Kept the existing Vite + React + TypeScript project structure and configuration.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed by Vite.

Note: newsletter delivery continues to use the project's existing `/api/send-email` endpoint and requires the matching backend configuration.
