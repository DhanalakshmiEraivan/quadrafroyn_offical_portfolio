# QuadraFroyn V36 — Software Development Service Page

This update replaces the generic `/services/software-development` page body with a bespoke white editorial software engineering experience.

## Included
- Editorial hero with original CSS dashboard and code-window mockups.
- Six selectable software capability panels.
- Three clearly labeled illustrative software product concepts (not client case studies).
- Four-step interactive development process.
- Technology groups, engineering principles, and project CTA.
- Responsive desktop/tablet/mobile layouts and reduced-motion handling.
- Uses existing React, React Router and Lucide dependencies; no new package is required.

## Run locally
```bash
npm install
npm run dev
```
Open the Vite URL and visit `/services/software-development`.

## Verify
```bash
npm run typecheck
npm run build
npm run lint
```

Note: verification in the preparation environment was blocked because the current `node_modules` installation has missing/incomplete type definitions. Reinstall dependencies in a clean environment before release. Technology examples are illustrative and should be adjusted to match the company's actual delivery capabilities.
