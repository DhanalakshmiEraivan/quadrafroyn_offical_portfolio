# QuadraFroyn V22 — Interaction and Studio Upgrade

## Included
- Replaced the Inside the Studio gallery with a 3D circular carousel of five animated concept payment cards. Includes a perspective stage, damped pointer parallax, card thickness, video texture, front/back flip, auto-rotation, pause/play, reset, arrow controls, dots, and touch swiping. The cards are visual concepts only; they are not connected to payment processing.
- Fixed Craft section composition and raised the green Q graphic behind the service cards while keeping card controls and content in the foreground. Responsive sizing and horizontal scroll snapping are included.
- Refined the homepage shortcut help with meaningful keyboard hints. Existing hero slideshow automatic progression and play/pause controls are preserved.
- Existing responsive visibility safeguards, Contact page refinements, and Freight services scroll-driven video section from V21 are retained.

## Run locally
1. Install Node.js LTS.
2. Extract the ZIP.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL printed by Vite.
5. Run `npm run build` to create the production bundle.

External Unsplash and CloudFront media require an internet connection. Concept card details are mock design data, not actual credentials.
