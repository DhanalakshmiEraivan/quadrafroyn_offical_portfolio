# Quadrafroyn update — About, Support, Career imagery & navigation

## Updated experiences
- `/about-us`: replaced with a compact editorial brand-story experience.
- `/support`: replaced with a focused support experience, documentation/contact pathways, searchable FAQs, and accessible accordion.
- `/career-guidance`: integrated four photographs supplied in the WhatsApp ZIP under `public/images/career-guidance/`.
- Homepage: added a career-guidance programme feature using the supplied photographs.
- Navigation: corrected the Web Development, Enterprise Content Management, BMS, Business Intelligence, Workforce Management, and Support dropdown destinations; added Company links.
- Back-to-top: consolidated to one persistent scroll-to-top control.

## Run
1. Install Node.js (LTS).
2. In this folder run `npm install`.
3. Run `npm run dev`.

## Notes
The supplied career-programme photographs are included locally; they do not depend on external image hosting. The new About and Support pages use remote Unsplash image URLs as editorial imagery. Existing project portfolio content and company details are retained; capability visuals are not presented as named client case studies.

Email/contact destinations remain the existing project contact channels. The Support page does not claim to create a ticket because no ticketing backend is configured.
