# Quadrafroyn Solutions — Enterprise Capability Pages

This project adds five dedicated capability routes to the existing Vite + React + TypeScript website:

- `/enterprise-ai` — enterprise AI architecture, layer explorer, use cases, lifecycle, and engineering principles.
- `/data-orchestration` — data pipeline architecture, selectable stages, deterministic transformation demo, execution log, reliability and implementation content.
- `/cloud-and-sovereign` — deployment model explorer, workload configuration, sovereignty control zones, cloud engineering and trade-off matrix.
- `/knowledge-graphs` — interactive illustrative knowledge graph, entity inspector, relationship filtering and path tracing, graph architecture and governance.
- `/agent-evaluation` — evaluation framework, deterministic simulated agent test, failure-case and trace panels, report, regression filters and evaluation methodology.

The pages use external Unsplash image URLs and existing project dependencies. Interactive laboratory data is illustrative frontend data; it is not connected to a production AI, data pipeline, cloud environment, knowledge graph database, or evaluation backend. Replace the example `hello@quadrafroyn.com` contact address if needed before publishing.

## Run locally

1. Extract the ZIP archive.
2. Open the `project` directory in VS Code.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

## Build checks

Run `npm run typecheck` and `npm run build` after dependencies install. In the environment used to prepare this archive, npm dependency installation timed out, so a successful production build could not be confirmed here.
