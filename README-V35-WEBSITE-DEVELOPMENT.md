# V35 — Website Development Service Page

This version replaces `/services/website-development` with a custom, responsive, white editorial-style website development service page. It preserves the existing application structure, shared header/footer, and other routes.

## Implemented sections
- Cinematic hero with browser-window concept visual and primary/secondary CTAs
- Credibility / development philosophy strip
- Editorial introduction
- Seven distinct service presentations
- Interactive four-stage process visual
- Technology and capabilities list
- Three illustrative website concept previews (brand, commerce, dashboard)
- Interactive before/refined direction toggle
- Delivery principles and quality checklist
- Transparent trust statement instead of fabricated testimonials
- Eight-item FAQ accordion
- Final contact CTA

## Run
```bash
npm install
npm run dev
```
Production checks:
```bash
npm run typecheck
npm run build
npm run lint
```

Images are sourced from Unsplash URLs and require internet access. Website previews are illustrative concepts, not claimed client projects. The technology list is presented as a potential toolkit; confirm the actual supported stack before publishing any capability claim. The project was not browser-tested in this environment because dependency installation did not complete, so run the checks above locally before deployment.
